ONNX Runtime (com.microsoft.onnxruntime:onnxruntime 1.31.1) is bundled inside this mod's jar, unmodified, as a
nested jar. The Apprentice wish box's trained layer uses it, on a server only, to run a sentence model.
Its licence, as its Maven pom declares it (MIT License), is reproduced below. The nested jar also carries the
project's own ThirdPartyNotices.txt for the libraries ONNX Runtime itself includes.
