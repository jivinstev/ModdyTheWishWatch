# Held redraws

Muse redraws of original icons that were set aside rather than shipped. `art/icons/held` is not
listed in `tools/gen-library-icons.py`'s CLUSTERS, so nothing in this folder reaches the game. The
old 16 px sprite stays until a better redraw lands in an `originals*` cluster.

Nothing is held right now. The last one, food_round, was redrawn as a bun in `originals_d`
(2026-10-02). Earlier attempts were held for having no grey body to take the wish colour, or for
being too like another icon (food_round's 93% silhouette match with the orb).
